# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability-reporting workflow under the repository's **Security** tab. Include the affected file or version, reproduction steps, potential impact, and any suggested mitigation.

This repository contains research software and classical simulations; it does not process secrets or control quantum hardware. Reports about scientific correctness that do not involve a security risk should use the bug-report template instead.
